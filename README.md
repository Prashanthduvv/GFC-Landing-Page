# GFC Landing Page

A responsive landing page for a combat sports brand built using React and Tailwind CSS.

## Features

* Responsive design (mobile to desktop)
* Smooth scrolling navigation
* Hero section with background image
* Sections: Fights, Fighters, Sponsors, News, Contact
* Animated sponsor slider
* Clean dark UI

## Tech Stack

* React
* Tailwind CSS
* JavaScript

## Run Project

```bash
git clone https://github.com/your-username/gfc-landing-page.git
cd gfc-landing-page
npm install
npm start
```

## Deployment

Can be deployed using Vercel or Netlify.

This project is created for practice/test and UI development.
